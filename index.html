UNIT 01

Introduction to Functions

What is a function?

A function is a relation where each input (x-value) maps to exactly one output (y-value). Graphically, a relation is a function if it passes the vertical line test: no vertical line crosses the graph more than once.

Function Notation

f(x) = 2x + 3 means "the output of f when the input is x". f(5) = 13 is a single value, not multiplication.

Domain & Range

Domain: all allowed x-values. Range: all resulting y-values. Interval notation: {x ∈ ℝ}, [−2, 5)

Inverse Functions

The inverse f−1(x) swaps x and y. Its graph is the reflection of f(x) in the line y = x.

The parent functions

Every function family grows from a simple "parent". Know their shapes, domains, and ranges:

NameEquationDomainRange
Linearf(x) = x{x ∈ ℝ}{y ∈ ℝ}
Quadraticf(x) = x²{x ∈ ℝ}{y ∈ ℝ, y ≥ 0}
Cubicf(x) = x³{x ∈ ℝ}{y ∈ ℝ}

Worked Example

If f(x) = x² − 3x + 1, find f(−2):

f(−2) = (−2)² − 3(−2) + 1 = 4 + 6 + 1 = 11

Common Mistakes
  • Treating f(x + h) as f(x) + h — you must substitute (x + h) everywhere x appears.
  • Forgetting restrictions: the domain of f(x) = √(x − 3) is x ≥ 3, and f(x) = 1/(x − 3) excludes x = 3.
  • Thinking f−1(x) means 1/f(x) — the inverse is not the reciprocal.

UNIT 02

Transformations of Functions

The master equation

y = a · f( k(x − d) ) + c
a — Vertical stretch/reflection

|a| > 1 stretches vertically, 0 < |a| < 1 compresses. a < 0 reflects in the x-axis. (x, y) → (x, ay)

k — Horizontal stretch/reflection

|k| > 1 compresses horizontally by 1/|k|. k < 0 reflects in the y-axis. (x, y) → (x/k, y)

d — Horizontal translation

Shift right by d. Note: it's (x − d), so y = f(x − 3) moves 3 units right. (x, y) → (x + d, y)

c — Vertical translation

Shift up by c. (x, y) → (x, y + c)

Mapping rule

Every point on the parent graph transforms by:

(x, y) → ( x/k + d , ay + c )

Apply stretches and reflections before translations (multiply before you add).

Worked Example

Describe the transformations of y = −2f(3x + 12) − 5.

First factor inside: y = −2f( 3(x + 4) ) − 5

  • a = −2 → vertical stretch by 2, reflection in x-axis
  • k = 3 → horizontal compression by 1/3
  • d = −4 → shift 4 units left
  • c = −5 → shift 5 units down
Common Mistakes
  • Reading d from an unfactored bracket: in f(2x − 6), d is 3, not 6. Factor first: f(2(x − 3)).
  • Thinking k > 1 stretches horizontally — it actually compresses.
  • Applying translations before stretches, which gives wrong coordinates.

UNIT 03

Quadratic Functions

The three forms

FormEquationTells you
Standardy = ax² + bx + cy-intercept is c
Factoredy = a(x − r)(x − s)x-intercepts (zeros) are r and s
Vertexy = a(x − h)² + kvertex is (h, k); axis of symmetry x = h
The Quadratic Formula
x = (−b ± √(b² − 4ac)) / 2a

Solves any ax² + bx + c = 0.

Discriminant
D = b² − 4ac

D > 0: two roots · D = 0: one root · D < 0: no real roots

Axis of Symmetry
x = −b / 2a

In factored form: x = (r + s)/2

Completing the square

Converts standard → vertex form: take half of b, square it, add and subtract it.

Worked Example

Convert y = 2x² + 8x + 5 to vertex form.

y = 2(x² + 4x) + 5 = 2(x² + 4x + 4 − 4) + 5 = 2(x + 2)² − 8 + 5

Vertex form: y = 2(x + 2)² − 3 → vertex (−2, −3)

Common Mistakes
  • Forgetting to factor a out first when a ≠ 1, and forgetting to multiply the subtracted term by a.
  • Sign errors in vertex form: y = (x + 2)² − 3 has vertex (−2, −3), not (2, −3).
  • Max/min word problems: the optimal value is the vertex — find h, then evaluate k.

UNIT 04

Exponential Functions

Exponent laws

Product
aᵐ · aⁿ = aᵐ⁺ⁿ
Quotient
aᵐ / aⁿ = aᵐ⁻ⁿ
Power of a power
(aᵐ)ⁿ = aᵐⁿ
Negative exponent
a⁻ⁿ = 1/aⁿ
Rational exponent
a^(m/n) = ⁿ√(aᵐ)
Zero exponent
a⁰ = 1 (a ≠ 0)

Exponential growth & decay

y = a · bx
  • a = initial value (the y-intercept)
  • b = growth/decay factor. b > 1 → growth; 0 < b < 1 → decay
  • Growth rate r: b = 1 + r. A 5% increase per year → b = 1.05
  • Half-life: y = a(½)t/h where h is the half-life period
  • Doubling: y = a(2)t/d where d is the doubling period

Unlike linear functions (constant differences), exponential functions have constant ratios between equally-spaced y-values. The x-axis (y = 0) is a horizontal asymptote.

Worked Example

A town of 24 000 people grows 3% per year. Population after 10 years:

P(t) = 24 000(1.03)t → P(10) = 24 000(1.03)10 ≈ 32 254

Common Mistakes
  • Confusing the factor with the rate: 3% growth means multiply by 1.03, not 0.03 or 3.
  • Using the growth equation when the time unit doesn't match (convert years ↔ months first).
  • Thinking exponential decay reaches zero — it approaches the asymptote but never touches it.

UNIT 05

Trigonometry of Acute & Obtuse Triangles

Primary trigonometric ratios (SOH · CAH · TOA)

Sine
sin θ = opposite / hypotenuse
Cosine
cos θ = adjacent / hypotenuse
Tangent
tan θ = opposite / adjacent

To find an angle from a ratio, use the inverse: θ = sin−1(ratio). For obtuse angles (90° < θ < 180°): sin θ is positive, cos θ and tan θ are negative, and sin θ = sin(180° − θ).

Sine law & cosine law

a/sin A = b/sin B = c/sin C   ·   c² = a² + b² − 2ab·cos C
  • Sine law — use when you have a matching side–angle pair (AAS, ASA, or SSA)
  • Cosine law — use for SAS (find the side opposite the known angle) or SSS (find any angle)
Worked Example

In △ABC, a = 7, b = 9, C = 52°. Find side c (SAS → cosine law):

c² = 7² + 9² − 2(7)(9)cos 52° = 49 + 81 − 126(0.6157) ≈ 52.4

c ≈ 7.2

Common Mistakes
  • Calculator in the wrong mode — make sure it's in degrees, not radians.
  • Pairing the wrong side with the wrong angle in sine law: side a must be opposite angle A.
  • Using cosine law when a side–angle pair already exists (sine law is faster).

UNIT 06

Trigonometric Functions

Radians

A radian measures an angle by arc length: 1 rad = angle where arc length = radius.

180° = π rad   ·   θ(rad) = θ(°) × π/180

Periodic & sinusoidal functions

A function is periodic if it repeats at regular intervals. Sinusoidal functions — y = sin x and y = cos x — are smooth periodic waves with:

Amplitude
|a| = (max − min)/2
Period
360°/k or 2π/k
Equation of axis
y = c = (max + min)/2
Phase shift
d units right
y = a sin( k(x − d) ) + c

Special triangles & the unit circle

Exact values come from two triangles: 30-60-90 (sides 1 : √3 : 2) and 45-45-90 (sides 1 : 1 : √2). On the unit circle, any angle θ gives the point (cos θ, sin θ).

Worked Example

For y = 3 sin(2(x − 30°)) + 1:

  • Amplitude = 3 · Period = 360°/2 = 180°
  • Phase shift = 30° right · Axis: y = 1
  • Range: {y ∈ ℝ, −2 ≤ y ≤ 4}
Common Mistakes
  • Period formula: the period is 360°divided by k — bigger k means a shorter period.
  • Mixing degrees and radians in the same calculation.
  • Forgetting that the max value is c + |a|, not just a.

UNIT 07

Sequences, Series & Financial Applications

Arithmetic vs. geometric

Arithmetic (add d)Geometric (multiply r)
General termtₙ = a + (n − 1)dtₙ = a · rⁿ⁻¹
Sum of n termsSₙ = n/2 · (2a + (n−1)d)Sₙ = a(rⁿ − 1)/(r − 1)
Example3, 7, 11, 15, … (d = 4)3, 6, 12, 24, … (r = 2)

A sequence is an ordered list of terms; a series is the sum of those terms.

Financial mathematics

Simple Interest
I = Prt

Interest on the principal only. Grows linearly (arithmetic).

Compound Interest
A = P(1 + i)ⁿ

i = rate per period, n = number of periods. Grows exponentially (geometric).

Annuities

Regular equal payments. Future value of an ordinary annuity: FV = R · ((1+i)ⁿ − 1)/i

Worked Example

$2 000 invested at 6%/a compounded annually for 8 years:

A = 2000(1.06)8 ≈ $3 187.70

Compounded monthly: i = 0.06/12 = 0.005, n = 96 → A = 2000(1.005)96 ≈ $3 228.28

Common Mistakes
  • Using rⁿ instead of rⁿ⁻¹ in the geometric general term — the first term already uses r⁰.
  • Forgetting to convert the annual rate: 6%/a compounded monthly → i = 0.5% per month and n = months.
  • Confusing the sequence (list of balances) with the series (their sum).
